Portable apps folder

Portable apps unzip into <folder>/<repo>.

Categories

Each category has its own folder: its portable apps unzip into <category folder>/<repo>; apps with no category use the portable apps folder above. Moving an app to another category, or changing a category's folder, moves the app's files too.

GitHub token

Optional. Without one GitHub allows 60 requests an hour per network; with one, 5,000. A fine-grained token with Public repositories (read-only) access and no other permissions is enough. Stored encrypted on this computer, never in config.json.

Advanced

Hand-edit for per-app overrides (asset pattern, install dir, installer kind/args, process name, release tag prefix).

git-updater updates

Off by default: git-updater updates itself only to stable releases. This is separate from the per-app beta setting.

Automatically

Off by default: git-updater stays on-demand. On, opening the window checks every tracked app — it never updates or installs anything automatically.
